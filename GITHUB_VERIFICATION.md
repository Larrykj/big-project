
2. **Delivery Prediction** - ML-based arrival forecasting
   ```python
   POST /api/predict-delivery
   ```

3. **Demand Forecasting** - Predict shipment volumes
   ```python
   GET /api/demand-forecast?region=Nairobi&days=7
   ```

4. **Anomaly Detection** - Identify unusual patterns
   ```python
   GET /api/anomaly-detection?truck_id=KBX-001
   ```

5. **Revenue Prediction** - Future revenue forecasting
